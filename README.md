# نجومي (Nujoomi)

تطبيق الأسرة لمتابعة الصلاة والمذاكرة ومهام البيت وكسب النجوم. يعمل على الآيباد والتابلت والجوال، ويُثبَّت من المتصفح (PWA).

- `docs/`: التطبيق المنشور على GitHub Pages.
- `source/`: الكود المصدري؛ `source/build.sh` يبني `docs/app.js`.
- `firestore.rules`: قواعد الخصوصية في Firebase (تُلصق في Firestore ← Rules).
